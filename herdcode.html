HOW THIS IS WIRED

Herd Chat — phone → Ollama nodes / LiteLLM directly, streaming.
Codex — phone → bridge on Hades → codex exec --oss --json -m <model> → that host's Ollama (the built-in --oss provider speaks the Responses API to Ollama ≥ 0.13.4 at localhost:11434).
Whole-herd Codex — point Codex at the LiteLLM gateway with the herd profile in the included codex-herd-config.toml (the gateway must answer /v1/responses — verify before relying on it).
Context — Codex + Ollama need OLLAMA_CONTEXT_LENGTH=65536 on the serving node, or tool calls silently truncate.
